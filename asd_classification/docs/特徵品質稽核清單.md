# 第一部｜Phase 0 稽核（n≈20,七項臨床錨定特徵＋一項人工標註）

> Phase 0 只做效果量估計,但**稽核標準不因樣本小而放鬆**——n≈20 時單一壞資料點對效果量的扭曲反而更大。

### P0-0E：🔴 ADOS 逐項編碼的取得與品質（v3.1 新增,blocking gate）

> **為什麼是 blocking gate**：效標關聯效度已是 Phase 0 的**主要分析**。A 區分數取不到,主要分析就做不了,只剩檢定力不足的組間比較。

- [ ] **取得 A 區逐項原始編碼**,至少含:

## 第 P0-3 關｜各項特徵的逐項稽核（F1–F5、F7–F8，＋人工標註 F6）

### P0-F1｜G1 答話文不對題(語意適切性)　效標：A8 Conversation（部分）

**效標對齊稽核（v3.1 新增）**
- [ ] A8 評的是**整體對話互惠**,本特徵只捕捉「回答切題與否」一面向,對應度中等。可與「多輪語意調適」「雙向不對稱性」合併為**對話互惠特徵組**再對 A8 分析。


- [ ] **句嵌入模型固定**:Phase 0 用 `paraphrase-multilingual-mpnet-base-v2`（多語,原生支援繁體;同計畫書 §5.0.5）並記錄版本;不可中途換模型。
- [ ] **是非題排除規則**:醫師的是非/選擇題(「是不是?」「要不要?」)其回答與提問相似度天然低,**必須排除**;排除規則寫死並抽驗 20 例。
- [ ] **極短回答處理**:「嗯」「對」等單詞回應的嵌入不穩定;設最短字數門檻並記錄。
- [ ] **理智檢查 (sanity check)**:人工挑 5 組「明顯答非所問」與 5 組「明顯切題」的配對,確認相似度分數方向正確、有區分度。

### P0-F2｜F1 即時回聲語言　🎯 效標：A3

**效標對齊稽核（v3.1 新增,務必先做）**
- [ ] **排除規則與 ADOS 一致**:A3 的編碼明確**排除「作為回答引導的複述」與「特定任務中作為記憶手段的複述」**。自動特徵必須實作相同排除,否則與臨床評分的相關會被系統性稀釋。
- [ ] 抽 10 個高分片段,人工核對是否符合 A3 的定義（對施測者最後一句或一連串陳述的即時重複）。


- [ ] **雙指標並列**:字面 n-gram 重疊率＋嵌入相似度,兩者都算(字面抓完整仿說,嵌入抓改述型)。
- [ ] **正常複述基準**:對照組本就有確認性重複(「你說車車?」)——**報告分布,不設絕對門檻**,由組間效果量說話。
- [ ] **理智檢查**:人工找出轉錄中肉眼可見的回聲語言實例 ≥ 5 例,確認演算法分數確實偏高。

### P0-F3｜F3 刻板／固定語句　🎯 效標：A4

**效標對齊稽核（v3.1 新增）**
- [ ] **注意 A4 的定義比本特徵更寬**:A4 涵蓋**延宕仿說**與其他**具一致語調型態**的高重複性語句。建議並列計算「延宕仿說」子特徵以提高對應度;預期相關為中等而非極高。
- [ ] **誘發不足的判讀**:A4 若因特質未被誘發而得 0,無法區分「真的沒有」與「沒誘發出來」。分析時**併報各受試者的可用發話量**,並排除發話量過低者。


- [ ] **n-gram 參數寫死**:n=2–5、重複 ≥ 3 次、功能詞串排除表——全部預先固定並記錄。
- [ ] **功能詞排除表抽驗**:「然後然後」「就是就是」是 4–6 歲常態,不是刻板語句;排除表需人工審一輪。
- [ ] **跨受試者特異詞串**:「僅該童使用且重複」的判定依賴全語料——n≈20 時基數小,**此子指標標記為探索性**。
- [ ] **與說話總量的相關**:話多的孩子重複機會多;報告特徵與總詞數的相關,必要時正規化。

### P0-F4｜B7 語者內嵌入變異(卡通腔代理)　效標：A2（語調向度,部分）

**效標對齊稽核（v3.1 新增）**
- [ ] **A2 為四向度合併評分**（語調／音量／節奏／語速）,單一特徵對應度有限。本特徵與 P0-F5（音量）、B4（重音）、C 區節奏特徵應合併為 **「A2 特徵組」**,以合成分數或多元迴歸對 A2 做整體效標分析。
- [ ] **A2 明確不含構音**——確認本特徵未被構音清晰度汙染。
- [ ] **A2 依表達語言程度相對評分**——記錄各受試者的語言程度,必要時作為共變項。


- [ ] **模型確認**:使用 **ECAPA-TDNN**（`speechbrain/spkrec-ecapa-voxceleb`, 192 維）;版本記錄於 P0-0F。備選 `microsoft/wavlm-base-plus-sv`（Microsoft, X-Vector 頭）,但**不可中途更換**。
- [ ] **嵌入抽取視窗統一**:固定長度(如 3 秒)視窗,不足者丟棄;段長影響嵌入穩定性,**不可混用不同長度**。
- [ ] **最低視窗數**:每位受試者 ≥ 15 個有效視窗,否則離散度估計不穩,標記低可靠。
- [ ] **與說話量的相關**:報告離散度與總說話時長的相關(排除「話多→變異大」的混淆)。
- [ ] **通道穩定性檢查**:同一 session 內若兒童移動造成錄音特性變化,嵌入變異會被通道汙染——抽 5 位受試者,人工聽其「高離散」視窗,確認是聲音風格變化而非收音變化。
- [ ] **理智檢查**:若醫師能指認 1–2 位「明顯會學卡通腔」的個案,確認其離散度確實偏高。

### P0-F5｜A12 音量跟隨(情境調節代理)　🎯 效標：A2（音量向度）

**效標對齊稽核（v3.1 新增）**
- [ ] 併入「A2 特徵組」一併分析（見 P0-F4）。
- [ ] 若 P0-0A 判定錄音為遠場且不可靠,本特徵擱置——**但仍應在 A2 特徵組中以其他向度（語調、節奏）替補**,不使 A2 效標分析整組落空。


- [ ] **🔴 可行性前置檢查**(在 P0-0A 已標記):遠場單麥克風＋兒童移動 → 強度量測不可靠。**先做**:抽 5 段,人工評估兒童音量變化是「真實音量」還是「距離變化」;不可靠 → **此特徵整項擱置**,在報告中記錄原因(不硬做)。
- [ ] **強度正規化**:以 session 層級正規化(z-score),消除整段錄音增益差異。
- [ ] **輪次配對**:與 P0-2 的配對規則一致。
- [ ] **最低配對數**:每位受試者 ≥ 15 對,否則迴歸斜率不穩。

### P0-F7｜多輪語意調適（v3.2 新增,非參數,參數為 0）

- [ ] **視窗大小不預設**:計算 3／5／7 輪三種視窗並全部報告。**不可沿用 SocialRecNet 的「5 turns 最佳」**——那是 13–17 歲青少年在 Emotions 活動的結果,4–6 歲兒童輪次更短、更由施測者主導。（v3.5.1 依原文 Fig. 3 補強:其各構念峰值本就不同——CONV@7、QSR/ARSC@3–5、OQR@5;三視窗全報並與各效標分別對應,正是正確做法。）
- [ ] **趨勢的操作型定義明確**:相似度隨輪次的迴歸斜率?變異縮小率?擇一寫死。
- [ ] **最低輪數**:每位受試者每視窗需 ≥ 3 個完整視窗,否則趨勢不穩。
- [ ] **🔴 地板效應檢查**:4–6 歲兒童本就不擅維持長篇互惠對話。**先看對照組的分布**——若對照組本身就沒有明顯調適,ASD 與對照的差距會被發展階段壓縮,此特徵在本年齡層可能不適用。**這是要如實報告的發現,不是失敗。**

### P0-F8｜雙向不對稱性（v3.2 新增,非參數）

- [ ] **雙向定義對稱**:「兒童跟隨醫師」與「醫師跟隨兒童」必須用**完全相同的算法**,只是方向相反;否則差值反映的是算法差異而非行為差異。
- [ ] **對應 ADOS OQR**:OQR 的定義即「施測者需多大程度調整行為以維持互動」。若能取得 OQR 分數,這是本特徵的天然效標。
- [ ] **⚠ 與施測者洩漏的交互**:本特徵**直接測量醫師的行為**,因此對施測者洩漏最敏感。P0-0C 若未通過,本特徵的解讀須特別保守。
- [ ] **理智檢查**:人工挑 3 位「醫師明顯很費力維持對話」的個案,確認不對稱性分數確實偏高。

### P0-F6｜B4 重音位置(人工標註)

- [ ] **標註者對診斷設盲**。
- [ ] **標註指引先行**:「強調位置恰當/不當」的操作型定義＋範例音檔,標註前先校準。
- [ ] **雙標信度**:全部雙標(量少),Cohen's κ ≥ 0.6 才可用(韻律判斷主觀性高,門檻略放寬但須揭露)。

- [ ] **缺值報告**:每特徵每受試者的可算/不可算狀態表;**缺值的組間差異須檢定並揭露**(缺值模式本身可能洩漏)。

## 第 P1-11 關｜主模型 vs 基線稽核（v3.6 改寫;前身為階梯升級稽核）

- [ ] **基線 B1（流分數堆疊;v3.6 由交付起點改列必報基線）**:每流折內 LR → 折外分數;融合層 3+1 參數。
  - **報告各流分數的折外 AUC（單流戰力表）與貢獻比例** $c_s = |w_s|\cdot\mathrm{sd}(f_s)/\sum_t |w_t|\cdot\mathrm{sd}(f_t)$ **及其跨種子／跨折穩定性**。
  - **🔴 塌陷檢查（v3.5 改寫）**:單流 $c_s > 0.9$ 即為警訊 → **先**檢查各流分數是否已折內標準化,**再**檢查**維度失衡**（高維流過擬合可在特徵完全標準化下造成塌陷——不可只歸因於尺度）。
  - **不穩定時退回 B0**:若貢獻比例在不同隨機種子間劇烈震盪,採 B0 的等權串接＋事後歸因。
- [ ] **🔴 主模型 M1 稽核（v3.6 新增）**:
  - 架構凍結並記錄:TCN 通道／層數／卷積塊構型與**實算參數量**、MLP 寬度;**參數/樣本比寫入論文限制節**。
